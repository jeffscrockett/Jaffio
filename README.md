# Jaffio releases

This public repository contains signed Jaffio APK releases for Android TV and Fire TV. The application source, signing material, obfuscation maps, configuration, and build diagnostics are not stored here.

Download the newest APK from [Releases](https://github.com/jeffscrockett/Jaffio/releases/latest). Each release includes a SHA-256 checksum file so the download can be verified before installation.

An APK necessarily contains executable code and resources that can be inspected. Public builds are minified production artifacts and are screened to exclude intended secrets, personal data, source files, debug symbols, and private build outputs.
